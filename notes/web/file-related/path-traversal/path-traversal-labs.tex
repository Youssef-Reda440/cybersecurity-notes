\nsection{Lab: File Path Traversal, Simple Case}

\begin{enumerate}
    \item Use Burp Suite to intercept a request that fetches a product image.

    \item Modify the \texttt{filename} parameter to the following payload:

          \begin{lstlisting}
../../../etc/passwd
    \end{lstlisting}

    \item Forward the modified request and inspect the response. The contents of \texttt{/etc/passwd} should be returned, solving the lab.
\end{enumerate}
