\section{Lab: Unprotected Admin Functionality}
\vspace{0.3cm}

\begin{enumerate}
    \item Navigate to \texttt{/robots.txt} and inspect the \texttt{Disallow} directive to discover the admin panel path.
    \item Navigate to the disclosed path, \texttt{/administrator-panel}.
    \item Delete the user \texttt{carlos} from the admin panel.
\end{enumerate}

\section{Lab: User Role Controlled by Request Parameter}
\vspace{0.3cm}

\begin{enumerate}
    \item Navigate to \texttt{/admin} and confirm that access is denied.
    \item Log in using the credentials \texttt{wiener:peter}.
    \item In Burp Proxy, enable interception for HTTP responses and submit the login form.
    \item Inspect the response and locate the cookie \texttt{Admin=false}.
    \item Change the cookie value to \texttt{Admin=true} and forward the response.
    \item Navigate to \texttt{/admin} and delete the user \texttt{carlos}.
\end{enumerate}

\section{Lab: User Role Can Be Modified in User Profile}
\vspace{0.3cm}

\begin{enumerate}
    \item Log in using \texttt{wiener:peter} and navigate to your account page.
    \item Use the feature to update your account email address.
    \item Inspect the response and locate your \texttt{roleid}.
    \item Send the email update request to Burp Repeater and add the following property to the JSON request body:

          \begin{lstlisting}
"roleid": 2
\end{lstlisting}

    \item Resend the request and verify that your \texttt{roleid} is now \texttt{2}.
    \item Navigate to \texttt{/admin} and delete the user \texttt{carlos}.
\end{enumerate}

\section{Lab: Method-Based Access Control Can Be Circumvented}
\vspace{0.3cm}

\begin{enumerate}
    \item Log in using the administrator credentials \texttt{administrator:admin}.
    \item Open the admin panel, initiate the promotion of \texttt{carlos}, and send the resulting request to Burp Repeater.
    \item Open a private browser window and log in as \texttt{wiener:peter}.
    \item Replace the session cookie in Repeater with the non-admin user's session cookie and resend the request. Observe the \texttt{Unauthorized} response.
    \item Change the HTTP method from \texttt{POST} to \texttt{POSTX} and resend the request. Observe the different error response.
    \item Use Burp Repeater's \textit{Change request method} option to convert the request to \texttt{GET}.
    \item Change the username parameter to \texttt{wiener} and resend the request to promote your account to administrator.
\end{enumerate}

\section{Lab: Referer-Based Access Control}
\vspace{0.3cm}

\begin{enumerate}
    \item Log in using \texttt{administrator:admin} and navigate to the admin panel.
    \item Promote \texttt{carlos} and send the HTTP request to Burp Repeater.
    \item Open a private browser window and log in using \texttt{wiener:peter}.
    \item Visit \texttt{/admin-roles?username=carlos\&action=upgrade} and observe that the request is rejected because the \texttt{Referer} header is missing.
    \item Replace the session cookie in Repeater with the non-admin user's session cookie, change the username parameter to \texttt{wiener}, and add a \texttt{Referer} header pointing to \texttt{/admin}.
    \item Resend the request to promote your own account to administrator.
\end{enumerate}
